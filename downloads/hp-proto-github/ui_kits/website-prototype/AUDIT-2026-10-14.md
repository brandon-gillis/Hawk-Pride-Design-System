# Production audit · 14 Oct 2026

Scope: website prototype (`ui_kits/website-prototype/`) and the design system it draws from.

## 1. CSS architecture
- **Before:** 613 inline `style={{}}` objects across 11 JSX files, plus ~160 lines of page CSS in a `<style>` tag in `index.html` (one block was pasted twice inside a media query), an inline `<style>` in Gate, 20 hardcoded hex fallbacks.
- **After:** 5 inline styles remain, all in `SiteMap.jsx` and all data-driven geometry (crop window, pin positions). No hex values in JSX.
- Shared patterns moved into the DS: `components/patterns.css` (layout, type sizes, heroes, section header, CTA band, footer, accordion, chip, summary rows, callout, text link, feature, price list, checklist).
- Page-only layouts moved to `ui_kits/website-prototype/site.css`, deduplicated.
- New tokens: `--section-y`, `--success-900`, `--danger-900`, `--danger-300`, `--info-900` (were undefined, used with fallbacks).

## 2. Mobile
- Body line-height was never set (fell back to ~1.2). Now `--lh-body` 1.5 on `.hp-root`.
- Page heroes: photo moves above the title at 16:9 on mobile; hero buttons go full-width under 560px.
- Booking flow: step bar shows numbers only with the current label; trip total is a collapsible summary at the top (the sidebar was pushed below the Continue button); Continue/Pay bar sticks to the bottom with safe-area padding.
- Site picker: map first, list without a nested scroll area.
- Events list stacks (was a squeezed two-column card). Event facts use a 2-up grid with clean dividers. Schedule rows stack.
- Home: pathway cards 16:11 without stagger (were four 3:4 cards, ~470px each); proof photo bleeds evenly; mosaic 2-up.
- Trails: stats 2-up, terrain cards 300px tall, UBW band photo 260px.
- Confirmation party rows, waiver rows, gate rows reflow under 560–700px.
- Tap targets under 40px per page dropped from 17–25 to 3 (remaining: staff demo links in the footer legal row, 36px small buttons with 44px hit areas).
- Mobile menu and site drawer: Esc closes, focus moves in, body scroll locks, current page marked.

## 3. Type and readability
- One headline system: `.hp-display` + size class (`hp-display-xl|l`, `hp-h1`–`hp-h4`) replaces ~90 ad-hoc font sizes (22, 24, 26, 28, 30, 34, 40, 48).
- Reading text uses `.hp-lede` / `.hp-body-l` with 62–68ch measure; card copy uses `.hp-card__text` (15/1.5).
- Section headers are identical on every page (Cabins previously used a different header without the gold rule).
- Eyebrow colours are classes (`--accent`, `--muted`) that flip on dark.

## 4. Components added to the DS
Section/SectionHeader, PageHero, CtaBand, SiteFooter (new `layout` group), Accordion, Feature, PriceList, SummaryRow (content), Chip, TextLink (core), Callout (feedback). `.hp-field` now styles `<textarea>`. Cards updated: Layout (new), Content, Core, Feedback.
Reused instead of re-built: Gallery filter now uses `Tabs` (pill); anchor buttons use `Button href`; event date chip uses `.hp-date`.

The prototype's `ProtoShell.jsx` carries same-markup copies of the new components and switches to the DS versions automatically once the bundle includes them.

## Pre-launch pass (14 Oct, second audit: site + admin + checkout)
- **Type tokens everywhere.** 160 hard-coded px font sizes across components.css, patterns.css, site.css and admin.css replaced by `--fs-*` tokens. New tokens: `--fs-body-s` 15 / `--lh-body-s`, `--fs-button` 17, `--fs-button-lg` 19, `--container-max-wide` 1280. Non-label 13px text (hints, fine print, legends, tooltips, footer legal) raised to 14px. Calendar weekday labels 11 → 12px.
- **Admin scale via tokens.** The "bump DS controls" override block is gone. `.adm` re-declares the small end of the ladder (caption 13 … body 17, button-lg 20, control height 48) and DS components inherit it. Removed 8 `!important` (link colour now `.adm a:not([class])`), the last `#fff`, a raw shadow, and the 1280px literal.
- **New DS component: Textarea** (label, top hint, error, live character count). Replaces the admin's local `Area` and the hand-built contact-form textarea. Field error/footer/count classes added to `.hp-field`.
- **Public calendar CSS** moved from admin.css to site.css (it isn't admin).
- **Mobile (390px) probe on 17 routes:** no horizontal overflow anywhere. Fixed: text links get a 44px hit area outside paragraphs; booking header logo 44px; checkout demo checkbox was a raw 13px input (now DS Checkbox); mobile calendar bars (6px) no longer intercept taps (agenda list below handles them); tight line-heights on trail labels, contact address, UBW tagline.
- **Line heights:** admin body/sub/dim now use `--lh-*` tokens; field hints/errors 1.45.
- Archived unused `UphillBothWays v1/v2.jsx` (258 inline styles, not loaded) to `_archive/`.
- Hex: only remaining hex in JSX is trail numbers ("#112"). No inline styles outside SiteMap geometry.
